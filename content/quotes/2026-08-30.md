# Daily Quote

> "It's through trying to do things we don't know how to do that we learn how to do them."

— William James

## Reflection

Every time I start a new feature or dive into an unfamiliar codebase, that initial feeling of incompetence is actually the exact mechanism of growth. If we only wrote code we already knew how to write, we would never build anything new. True progress lives right on the other side of that uncomfortable blank editor screen.
