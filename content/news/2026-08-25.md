# Tech Update

## Headline

Ambient Context: A macOS Menu Bar App for Text-Based Screen Memory

## Summary

Ambient Context is a macOS menu bar app that reads the text of a focused window every few seconds using the Accessibility API, bypassing screenshots, video, and OCR. It logs plain markdown files organized by day into a user-chosen folder, complete with an AGENTS.md file to explain the format to AI models like Claude Code.

## Why It Matters

Developers can use this open-source tool to give AI file access to daily activity logs, enabling queries like "what did I work on Tuesday?" or building persistent project memory.

## Source

Hacker News: Front Page (https://github.com/dragthelake/ambient-context)
