# Tech Update

## Headline

Eiliko maker hires an independent security firm after a Verge report on insecure robots

## Summary

Following a report by The Verge highlighting severe security flaws, the maker of the Eiliko robot charm announced it is hiring an independent security firm. The cute AI-conversation robot was found to be a security nightmare, allowing hackers to easily read complete transcripts of user conversations.

## Why It Matters

This serves as a cautionary tale for developers building consumer AI or IoT hardware regarding the critical importance of end-to-end security and data privacy.
