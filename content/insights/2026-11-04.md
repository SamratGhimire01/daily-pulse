# Developer Insight

## Topic

Using `git worktree` for Parallel Feature Development

## Explanation

Instead of stashing changes or cloning a repository multiple times to work on two branches simultaneously, Git worktrees allow you to check out multiple branches of the same repository into separate directories. This links them to the same underlying Git history, letting you run tests in one branch while actively writing code in another without losing your terminal state.

## Practical Example

```bash
# Create a new worktree for a bugfix branch in a sibling directory
git worktree add ../project-bugfix hotfix/login-crash

# List all active worktrees
git worktree list

# Remove the worktree when done
git worktree remove ../project-bugfix
```

## Takeaway

Worktrees eliminate the friction of context switching by keeping separate branches physically separated on your disk while sharing a single git database.
