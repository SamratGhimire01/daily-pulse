# Developer Insight

## Topic

Using Git `patch` Interactive Mode for Selective Commits

## Explanation

When working on a feature, it's common to modify multiple unrelated files or make several distinct changes within the same file. Instead of resorting to messy `git add` hacks, `git add -p` lets you review individual hunks of changes interactively and choose precisely what goes into your next commit. This keeps your commit history clean, atomic, and easy to review later.

## Practical Example

Run `git add -p` in your terminal. Git will present your modified files hunk by hunk, prompting you with choices like this:

```text
Stage this hunk [y,n,q,a,d,/,e,?]? 
```

Press `y` to stage the hunk, `n` to skip it, or `e` to manually edit the hunk before staging.

## Takeaway

Mastering selective staging ensures your git history tells a clear story, making code reviews and debugging significantly easier for everyone on the team.
