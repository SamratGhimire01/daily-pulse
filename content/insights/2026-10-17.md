# Developer Insight

## Topic

Git Worktree for Context Switching

## Explanation

`git worktree` allows you to check out multiple branches of the same repository into separate directories simultaneously. Instead of stashing changes, committing half-done work, or running separate clones to review a pull request, you get isolated working directories backed by the same local `.git` history. This eliminates the friction of context switching between features and bug fixes.

## Practical Example

```bash
# Create a new worktree for a bugfix branch in a parallel directory
git worktree add ../my-project-hotfix hotfix/login-crash

# List all active worktrees
git worktree list

# Remove the worktree when done
git worktree remove ../my-project-hotfix
```

## Takeaway

Use worktrees to keep your current workspace pristine while investigating urgent issues elsewhere. It saves time and prevents accidental context bleeding between tasks.
